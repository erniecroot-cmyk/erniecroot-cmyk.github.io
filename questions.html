Some Research Questions

I have decided to create some questions that are a lot harder than usual, now that AI is able to do things like prove the Riemann zeta function has no zeros s with Re(s) > 7/8. I decided to choose some questions that are open-ended, "meta", and likely won't all be solved so quickly. I will add to the list as I think of interesting ones.

  1. Now that we know that a very strong form of the Erdos-Turan conjecture is true, and perhaps soon we will even have strong bounds for polynomial progressions, perhaps it is a good idea to ask about more general types of sequences along these lines. People are trying this; for example, they are proving results about Piatetski-Shapiro sequences, like for example arithmetic progressions x, x + [yc], 2[yc], ..., x + k [yc]. But let us try to be even more ambitious than that, and I will make it kind of an inverse question. First, observe that one way to think about an arithmetic progression x, x+d, x+2d, ..., x+kd, is that it's saying that you have a very compressed representation -- just two numbers x and d -- that determines k+1 different numbers in your set. Furthermore, you do not need many arithmetic operations to compute all those k+1 numbers. My question is: which functions f that take as input two numbers -- call them x and d -- and then output k integers (x1, ..., xk) using at most (k+1)A arithmetic operations (which could include addition, multiplication, division, exponentiation, rounding, and maybe modular arithmetic), for some A > 0, have the property that for every positive upper density subset S of the positive integers, there exist integers x and d such that if you plug them into f, the resulting sequence (x1, ..., xk) is contained in S x S x S x ... x S?

  2. The kinds of set sizes for maximal sets S in [N] without certain patterns (3APs, solutions to x+y=z, square differences), are either of the form cN (e.g. in the case of maximal sets S without solutios to x+y=z), or quasipolynomial / Behrend-like (i.e. of the shape N exp(-(log N)c) ), or Nc. Are there natural problems with forbidden patterns where the extremal sets S have size, say, N / log N or other such intermediate function?

  3. An interesting phenomenon is the fact that greedy algorithms often lead to constructions that underperfom more "global methods", with Sidon sets being a prime example: if you greedily construct a Sidon set by picking the next available positive integer while preserving the Sidon property, you get a set Sidon set in [N] of size only about N1/3; but we know that the largest Sidon set in [N] has size about sqrt(N). However, you can create a large Sidon set greedily using prime numbers, since primes can be constructed greedily (if you have chosen the first k primes, pick the next integer not divisible by any of them, and then that with be the next prime in the sequence). The construction of your Sidon set involves simply computing [M log(p)] for each prime p you greedily choose, for some choice of M. In fact, you can make this into a greedy Sidon construction without direct mention of primes at all, by simply running though the numbers n=2,3,4,5,... where at each step you add [M log n] to your set if the Sidon property is maintained. Are there other types of greedy algorithms like this for constructing Sidon sets or even other kinds of sets -- such as sets without three-term progressions -- that appear in discrete analaysis?

  4. Polynomial method approaches, like Stepanov's proof of Weil-type bounds for curves over finite fields, are still somewhat mysterious. I feel like there should be a better explanation about why they work and how to tell if they have a chance of working on a particular problem, besides simply "well, just write down a polynomial that vanishes on your set and see if it works." I feel like we are missing something important about the success of this method. I guess what I am looking for is a "story" to help one decide when and how to go down the path of trying the method, and then not giving up if it fails on the first attempt, because maybe one has some strong reason to suspect the method will succeed.

  5. Godel's Incompleteness Theorem tells us that there are hard limits on what theorems we can hope to prove. However, I have not really seen an interesting and natural class of problems in additive combinatorics / discrete analysis that one can point to and say that some problem in the class is unprovable (using certain axioms of arithmetic, set theory, etc.). What are some interesting classes of problems of this type?

  6. Many extremal solutions to problems in discrete analysis and additive combinatorics -- such as finding maximal Sidon sets -- have an algebraic structure. What are some very natural problems where the extremal -- or near-extremal -- solution does not have an algebraic structure? Perhaps the largest subset of Zp, p prime, without 3APs is like this; however, it is still possible that that set has hidden algebraic structure. For example, the Behrend construction is "algebraic", in a sense, but known to be far from optimal.

  7. The Maier matrix method shows that prime numbers can fail to have the expected number of elements in intervals of the shape [x, x + (log x)c] for c > 1. Are there other sets where you get an unexpected distribution result for the primes like this? I suppose one can get a similar result by replacing long intervals with long arithmetic progressions, or even long polynomial progressions. What I am looking for here is some new structure besides these, a structure where one can get a similar result to Maier's but not via a straighforward generalization of his proof. Is there a new kind of proof besides Maier's for failure of equidistribution?

  8. The operations of multiplicaton and addition (and subtraction and division) probably arose from practical considerations in early human civilizations, and then they were related to the spatial world of geometry; from there, many deep and surprisng discoveries were made about them (operations), including the very idea that something like Fermat's Last Theorem could even be proved. I am wondering if there is anything really special about these operations, or if similar complexity could arise from some other ones. We could consider novel operations on pairs of integers and where, say, the number of bit-operations to compute them is restricted. If x and y are the integers and f(x,y) represents the operation applied to the pair, then say it can be computed using at most as many bit-operations as to multiply two comparable-sized integers. We could further assume the operations are commutative and associative. Then we could ask whether a rich and varied collection of deep results about these operations as enjoyed by addition and multiplication would arise. If so, it would somewhat diminish the specialness of the results we now see in number theory. Of course, different operations can be computed via combining several steps of addition, multiplication, modding, and a few more, and if your new operations are sufficiently rich, you could compute additions and multiplications using them; but translating results of number theory into statements about operations like f(x,y) and vice versa might end up looking "ugly", and what I am after is "beautiful" results.

  9. Base-2 pseudoprimes are odd composite numbers n such that 2n-1mod n = 1. It turns out that all but a vanishingly small proportion of the odd intgers n in [N] where 2n-1 mod n = 1, are prime; so, base-2 pseudoprimes are very rare. This woud be a problem if you wanted a machine learning model to learn the function that returns 1 if a number is prime and 0 if it is composite, since the (input, output) dataset for this function would have very high overlap with the dataset for the function that returns 1 if 2n-1 mod n = 1, and returns 0 otherwise. Are there other low-complexity (small number of bit-operations) functions besides this (and similar ones, using other bases) that agree with the prime number indicator function? Or are all such low-complexity functions closely-related to these?

  10. The idea of writing numbers in different bases is often seen as a topic more for "recreational math" than "research math", though it does have a rich history. The ancient Babylonians, for example, worked in base-60, which they inherited from the Sumerians thousands of years ago; and then regarding base-2, binary numbers are important in our modern digital era. Working in different bases does have a few connections to research math beyond just to serve as a number system for computational and practical reasons. For example, the p-divisiblity of binomial coefficients is intimately related to base-p respresentations of certain numbers via Kummer's theorem; there is also the connection to Sylow-p subgroups of the symmetric group Sn acting on certain subsets of {1,...,n}; and there are also p-adic numbers Zp, which are not really base-p representations, but there are some connections between them. What I am wondering is whether there are other, very natural and general ways that base-b representations enter the picture in some area of math, in a way not yet discovered. For example, a certain type of interesting object (in group theory, say, or even just combinatorics) exists if and only if the base-b representations of certain base-b numbers have some certain digit properties.

  11. This problem can be thought of as a generalization of problem 9 above: in my previous problem about pseudoprimes, you can think of checking when numbers n satisfy 2n-1mod n = 1 as being a "near-miss" for a way to perfectly detect primes; but you can also think of it in terms of a failure of a statistical version of Occam's Razor, since the (input, output) data would 99.99% of the time agree with prime detection, and then would also have a simpler explanation than "1 if n is prime, 0 if not". What I am wondering is if there are other decision problems like this, for other kinds of set membership questions, where a similar statistical Occam's Razor approach fails. That is, problems where 99.999% of the (input, output) examples for some set membership problem -- for a well-studied and understood type of set -- agree with (input, output) examples for some other set membership problem, yet where the decision function for this other set has a shorter and simpler description than the original.

  12. This problem can be thought of as kind of the opposite of problem 3 above: are there interesting sets that have a greedy or inductive definition that also have global / non-greedy / non-inductive definitions? Prime numbers are one example. You can inductively construct primes by picking the next prime to be the next integer not divisible by any previous prime; but you can also define them non-greedily by saying that a number is prime if it has no non-trivial factorization. But now consider a set like the Golomb primes. These are odd primes p where you choose the next one to be any such that p-1 is not divisible by any of the previous ones. It's much harder to find a non-greedy definition for this set. What are some interesting sets in number theory, discrete math, or combinatorics that are like the full set of primes but maybe not like Golomb primes in this regard (assuming Golomb primes don't have a nice non-greedy definition)? I am not looking here for a literature search where you just pick ones that are already known to have this property. I am looking for novel and unexpected examples where some real work is needed to do produce the non-greedy definition. In fact, is there a whole, interesting class of sets that have this property?

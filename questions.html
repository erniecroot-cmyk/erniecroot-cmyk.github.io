Some Research Questions

I have decided to create some questions that are a lot harder than usual, now that AI is able to do things like prove the Riemann zeta function has no zeros s with Re(s) > 7/8. I decided to choose some questions that are open-ended, "meta", and likely won't all be solved so quickly. I will add to the list as I think of interesting ones.

  1. Now that we know that a very strong form of the Erdos-Turan conjecture is true, and perhaps soon we will even have strong bounds for polynomial progressions, perhaps it is a good idea to ask about more general types of sequences along these lines. People are trying this; for example, they are proving results about Piatetski-Shapiro sequences, like for example arithmetic progressions x, x + [yc], 2[yc], ..., x + k [yc]. But let us try to be even more ambitious than that, and I will make it kind of an inverse question. First, observe that one way to think about an arithmetic progression x, x+d, x+2d, ..., x+kd, is that it's saying that you have a very compressed representation -- just two numbers x and d -- that determines k+1 different numbers in your set. Furthermore, you do not need many arithmetic operations to compute all those k+1 numbers. My question is: which functions f that take as input two numbers -- call them x and d -- and then output k integers (x1, ..., xk) using at most (k+1)A arithmetic operations (which could include addition, multiplication, division, exponentiation, rounding, and maybe modular arithmetic), for some A > 0, have the property that for every positive upper density subset S of the positive integers, there exist integers x and d such that if you plug them into f, the resulting sequence (x1, ..., xk) is contained in S x S x S x ... x S?

  2. The kinds of set sizes for maximal sets S in [N] without certain patterns (3APs, solutions to x+y=z, square differences), are either of the form cN (e.g. in the case of maximal sets S without solutios to x+y=z), or quasipolynomial / Behrend-like (i.e. of the shape N exp(-(log N)c) ), or Nc. Are there natural problems with forbidden patterns where the extremal sets S have size, say, N / log N or other such intermediate function?

  3. An interesting phenomenon is the fact that greedy algorithms often lead to constructions that underperfom more "global methods", with Sidon sets being a prime example: if you greedily construct a Sidon set by picking the next available positive integer while preserving the Sidon property, you get a set Sidon set in [N] of size only about N1/3; but we know that the largest Sidon set in [N] has size about sqrt(N). However, you can create a large Sidon set greedily using prime numbers, since primes can be constructed greedily (if you have chosen the first k primes, pick the next integer not divisible by any of them, and then that with be the next prime in the sequence). The construction of your Sidon set involves simply computing [M log(p)] for each prime p you greedily choose, for some choice of M. In fact, you can make this into a greedy Sidon construction without direct mention of primes at all, by simply running though the numbers n=2,3,4,5,... where at each step you add [M log n] to your set if the Sidon property is maintained. Are there other types of greedy algorithms like this for constructing Sidon sets or even other kinds of sets -- such as sets without three-term progressions -- that appear in discrete analaysis?

  4. Polynomial method approaches, like Stepanov's proof of Weil-type bounds for curves over finite fields, are still somewhat mysterious. I feel like there should be a better explanation about why they work and how to tell if they have a chance of working on a particular problem, besides simply "well, just write down a polynomial that vanishes on your set and see if it works." I feel like we are missing something important about the success of this method. I guess what I am looking for is a "story" to help one decide when and how to go down the path of trying the method, and then not giving up if it fails on the first attempt, because maybe one has some strong reason to suspect the method will succeed.

  5. Godel's Incompleteness Theorem tells us that there are hard limits on what theorems we can hope to prove. However, I have not really seen an interesting and natural class of problems in additive combinatorics / discrete analysis that one can point to and say that some problem in the class is unprovable (using certain axioms of arithmetic, set theory, etc.). What are some interesting classes of problems of this type?

  6. Many extremal solutions to problems in discrete analysis and additive combinatorics -- such as finding maximal Sidon sets -- have an algebraic structure. What are some very natural problems where the extremal -- or near-extremal -- solution does not have an algebraic structure? Perhaps the largest subset of Z_p, p prime, without 3APs is like this; however, it is still possible that that set has hidden algebraic structure. For example, the Behrend construction is "algebraic", in a sense, but known to be far from optimal.

  7. The Maier matrix method shows that prime numbers can fail to have the expected number of elements in intervals of the shape [x, x + (log x)c] for c > 1. Are there other sets where you get an unexpected distribution result for the primes like this? I suppose one can get a similar result by replacing long intervals with long arithmetic progressions, or even long polynomial progressions. What I am looking for here is some new structure besides these, a structure where one can get a similar result to Maier's but not via a straighforward generalization of his proof. Is there a new kind of proof besides Maier's for failure of equidistribution?

  8. The operations of multiplicaton and addition (and subtraction and division) probably arose from practical considerations in early human civilizations, and then they were related to the spatial world of geometry; from there, many deep and surprisng discoveries were made about them (operations), including the very idea that something like Fermat's Last Theorem could even be proved. I am wondering if there is anything really special about these operations, or if similar complexity could arise from some other ones. We could consider novel operations on pairs of integers and where, say, the number of bit-operations to compute them is restricted. If x and y are the integers and f(x,y) represents the operation applied to the pair, then say it can be computed using at most as many bit-operations as to multiply two comparable-sized integers. We could further assume the operations are commutative and associative. Then we could ask whether a rich and varied collection of deep results about these operations as enjoyed by addition and multiplication would arise. If so, it would somewhat diminish the specialness of the results we now see in number theory. Of course, different operations can be computed via combining several steps of addition, multiplication, modding, and a few more; but translating results of number theory into statements about operations like f(x,y) might end up looking "ugly", and what I am after is "beautiful" results.

  9. Base-2 pseudoprimes are odd composite numbers n such that 2n-1mod n = 1; so, all but a vanishingly small proportion of the odd intgers n in [N] where 2n-1 mod n = 1, are prime. This woud be a problem if you wanted a machine learning model to learn the function that returns 1 if a number is prime and 0 if it is composite, since the (input, output) dataset for this function would have very high overlap with the dataset for the function that returns 1 if 2n-1 mod n = 1, and returns 0 otherwise. Are there other low-complexity (small number of bit-operations) functions besides this (and similar ones, using other bases) that agree with the prime number indicator function? Or are all such low-complexity functions closely-related to these?

Check back later, as I will add more problems...

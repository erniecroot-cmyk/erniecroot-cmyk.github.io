Some Research Questions

I have decided to create some questions that are a lot harder than usual, now that AI is able to do things like prove the Riemann zeta function has no zeros s with Re(s) > 7/8. I decided to choose some questions that are open-ended, "meta", and likely won't all be solved so quickly. I will add to the list as I think of interesting ones.

  1. Now that we know that a very strong form of the Erdos-Turan conjecture is true, and perhaps soon we will even have strong bounds for polynomial progressions, perhaps it is a good idea to ask about more general types of sequences along these lines. People are trying this; for example, they are proving results about Piatetski-Shapiro sequences, like for example arithmetic progressions x, x + [yc], 2[yc], ..., x + k [yc]. But let us try to be even more ambitious than that, and I will make it kind of an inverse question. First, observe that one way to think about an arithmetic progression x, x+d, x+2d, ..., x+kd, is that it's saying that you have a very compressed representation -- just two numbers x and d -- that determines k+1 different numbers in your set. Furthermore, you do not need many arithmetic operations to compute all those k+1 numbers. My question is: which functions f that take as input two numbers -- call them x and d -- and then output k integers (x1, ..., xk) using at most (k+1)A arithmetic operations (which could include addition, multiplication, division, exponentiation, rounding, and maybe modular arithmetic), for some A > 0, have the property that for every positive upper density subset S of the positive integers, there exist integers x and d such that if you plug them into f, the resulting sequence (x1, ..., xk) is contained in S x S x S x ... x S?

  2. The kinds of set sizes for maximal sets S in [N] without certain patterns (3APs, solutions to x+y=z, square differences), are either of the form cN (e.g. in the case of maximal sets S without solutios to x+y=z), or quasipolynomial / Behrend-like (i.e. of the shape N exp(-(log N)c) ), or Nc. Are there natural problems with forbidden patterns where the extremal sets S have size, say, N / log N or other such intermediate function?

  3. An interesting phenomenon is the fact that greedy algorithms often lead to constructions that underperfom more "global methods", with Sidon sets being a prime example: if you greedily construct a Sidon set by picking the next available positive integer while preserving the Sidon property, you get a set Sidon set in [N] of size only about N1/3; but we know that the largest Sidon set in [N] has size about sqrt(N). However, you can create a large Sidon set greedily using prime numbers, since primes can be constructed greedily (if you have chosen the first k primes, pick the next integer not divisible by any of them, and then that with be the next prime in the sequence). The construction of your Sidon set involves simply computing [M log(p)] for each prime p you greedily choose, for some choice of M. Are there other types of greedy algorithms like this for constructing Sidon sets or even other kinds of sets -- such as sets without three-term progressions -- that appear in discrete analaysis?

  4. Polynomial method approaches, like Stepanov's proof of Weil-type bounds for curves over finite fields, are still somewhat mysterious. I feel like there should be a better explanation about why they work and how to tell if they have a chance of working on a particular problem, besides simply "well, just write down a polynomial that vanishes on your set and see if it works." I feel like we are missing something important about the success of this method. I guess what I am looking for is a "story" to help one decide when and how to go down the path of trying the method, and then not giving up if it fails on the first attempt, because maybe you have some strong reason to suspect the method will work.

Check back later, as I will add more problems...
